# 3D Art Gallery

Interactive 3D art gallery built with Three.js — portfolio exhibition for artists and designers.

## Author

**Nicolás Contigliani** — [LinkedIn](https://www.linkedin.com/in/nicolas-contigliani/)

## Quick Start

```bash
npm install
npx vite
```

Then open the local URL shown in the terminal.

## Requirements

- Node.js
- VS Code (recommended)

## Notes

- Large 4K textures use GitHub LFS; if broken, download textures/models manually.
- Full tutorial: [YouTube](https://youtu.be/vfMizAmPprs)
